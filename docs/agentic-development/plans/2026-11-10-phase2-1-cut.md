# Phase 2 · PR 1 — Cut removed features: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Delete every feature the owner removed (Meals & Snacks, Instamart shop + Swiggy, Pings, Paper Notes, Personal plans, People page, WFH requests) so the remaining app is small, green, and ready to be rebuilt in the new design.

**Architecture:** Pure deletion plus the minimum edits that keep the legacy shell compiling. No new UI: the legacy Home (`components/workspace/portal.tsx`) loses its pantry, planner and paper-note widgets and is otherwise left alone, because PR 2–3 replace it wholesale. Postgres tables for removed features stay in production untouched; the app just stops creating and reading them.

**Tech Stack:** Next.js 16.4.3 App Router, React 19, Vitest, Playwright, Postgres (`pg`) + JSON store.

**Spec:** `docs/agentic-development/specs/2026-11-09-phase2-scope-design.md` ("Removed" table, "Left to the builder", "Amendments → Delivery plan" item 1).

**Branch:** `phase2-cut`, stacked on `admin-member-roles`. PRs 2–7 get their own plans, written when this one is merged or green.

## Global Constraints

- Two roles only; members never see admin UI; every API checks its own access (Phase 1 holds).
- Speak Up stays anonymous and usable signed out. `submitterIdentity`, `grievanceIdsFromCookie`, `grievancesFromIds`, `awayForDevice` in `lib/submitter.ts` must survive.
- Any Store change lands in `lib/types.ts` (interface), `lib/jsonstore.ts`, `lib/pgstore.ts` and `tests/store/contract.ts` together.
- **No `DROP TABLE`, no destructive SQL.** Remove the `CREATE TABLE IF NOT EXISTS` blocks for `orders`, `pings`, `planner_days`, `provider_records` from `lib/pgstore.ts`; existing production tables and rows are left as they are.
- Not removed in this PR (later PRs replace them): check-in/check-out and `/attendance`, Events page, `/steps`, `/wifi`, Settings, Help, Notice board, the legacy CSS files, `workspace_profiles`.
- `/snacks` will return in PR 4 as "Tea & snacks"; until then it redirects Home with a **temporary** (307) redirect.
- Removed page URLs redirect Home (307), never 404: `/pantry`, `/snacks`, `/planner`, `/people`, `/admin/pantry`. Removed API routes simply 404.
- Commit identity: `Gautham Muraleedharan <gautham.muraleedharan@innovinlabs.com>` via `GIT_AUTHOR_*`/`GIT_COMMITTER_*`; never stage the `AGENTS.md` next-dev block.
- Verify per task with `npm run typecheck` (check the exit code), `npm test`, and only the affected Playwright specs.

## Review Focus

1. **Postgres that still has the old tables and rows** (production): the app must start and every kept page must load. → Task 5 upgrade check.
